# Roadmap

## Short Term

- Improve test coverage around storage and message routing
- Add Docker deployment examples
- Add systemd deployment documentation
- Improve locale coverage and invite community translations
- Add export tools for customer history

## Mid Term

- Split the single-file bot into smaller modules
- Add optional FAQ auto-replies
- Add conversation status, such as open, pending, resolved
- Add multi-agent support for teams with several support operators
- Add customer search and filtering commands

## Long Term

- Add an optional web admin dashboard
- Add analytics for customer intent, response time, and common questions
- Add CRM integrations through optional adapters
- Add privacy controls for retention and data export
- Add plugin-style extension points
